Atlasecho Tools

Small command-line tools that the owner of the Atlasecho YouTube channel runs on their own computer to publish videos and manage their own accounts.

What it doesPrivacy policyContact

What it does

These tools are not a public service. There is no sign-up, and nobody other than the channel owner uses them. They connect to Google APIs with OAuth so the owner can:

  • YouTube Data API: upload videos made for the channel, set their titles, descriptions, captions, thumbnails and publish times, and post or manage comments on the channel's own videos.
  • YouTube Analytics API: read the channel's own statistics (views, watch time, retention) for a weekly report.
  • Gmail API: let the owner search, read, label and organise mail in their own mailbox, and draft or send messages they have approved.

Privacy policy

Effective 20 November 2026

Who this covers

The only user of these tools is the owner of the Atlasecho channel, acting on their own Google accounts. The tools do not collect information from viewers, commenters or anyone else.

What data is accessed

  • YouTube: the owner's channel, its videos, captions, comments and analytics, only as needed for the actions listed above.
  • Gmail: the owner's messages, labels and filter settings, only when the owner asks the tools to act on their mail.
  • OAuth tokens issued by Google for the owner's accounts.

How it is stored

Tokens and any data the tools read are kept only on the owner's own computer. Nothing is sent to a server run by these tools, because there isn't one. Reports and files the tools create stay on that computer.

Sharing

Data is not sold, rented or shared with anyone, and is not used for advertising. It is not used to train machine-learning models offered to others.

Google API Services User Data Policy

The use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

Access can be removed at any time at myaccount.google.com/permissions. Deleting the token files on the owner's computer also stops all access.

Changes

If this policy changes, the effective date above will be updated.
